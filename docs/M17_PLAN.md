# Milestone 17 — Asset Pipeline: implementation plan

Goal (ROADMAP): mesh/material/audio loading, asset management, hot-reloading,
LODs, material variants and texture streaming. Proof: load and render a glTF
mesh with textures at 60 fps with zero validation errors.

The existing code already decodes GLB with embedded textures and renders it
through the toon BDA texture path (`Toon::createMeshFromAsset`, capability 32).
M17 builds a real pipeline around that path; it does not replace the toon
material model.

## Steps (one commit each, in order)

1. **M17.1 Asset manager core** — CPU registry with typed handles, path
   dedup, refcounts, byte accounting and a dirty/reload queue. T1 tests.
2. **M17.2 File watching + hot reload** — poll-based `FileWatcher` and a
   `HotReloadCoordinator` that feeds the manager's reload queue. T1 tests
   with real temp files.
3. **M17.3 glTF material → toon mapping + variants** — extend the GLB
   decoder's material record (PBR factors, extra texture slots, alpha mode,
   double-sided, emissive), map it to the M9.5 toon capability bitmask, and
   add named material variants (default/damaged/shielded/highlighted). T1
   tests.
4. **M17.4 LOD chains + meshoptimizer** — FetchContent meshoptimizer; vertex
   weld/optimize/simplify utilities; asset-level `LodChain` with hysteresis
   and distance selection. T1 tests.
5. **M17.5 Texture streaming** — mip-chain generation, byte budget with LRU
   residency, request/eviction, `starforge::StreamingTexture` public facade,
   and a `Toon::createMeshFromAsset` overload that uploads a chosen mip. T1
   + public API tests.
6. **M17.6 External glTF + audio files** — FetchContent tinygltf for ASCII
   `.gltf`/external-URI loading; file-based audio loading via miniaudio's
   decoder. Tests for both paths.
7. **M17.7 Authored content** — deterministic generator script producing a
   stylised hero ship and station `.glb` (multiple meshes, materials and
   embedded textures) committed under `assets/models/`. Loader tests.
8. **M17.8 Game integration + proof** — load the hero ship/station through
   the asset manager, render them with mapped toon materials + variants +
   LODs, wire hot reload and texture streaming, show asset status in the
   HUD, and add a headless GPU proof at the frame budget.
9. **M17.9 Docs + final verification** — update ROADMAP/ARCHITECTURE/
   public-api docs, full CTest (CPU + public + GPU) and zero validation
   errors; final commit.

## Decisions
- Keep the hand-rolled GLB decoder (it is proven by GPU tests) and add
  tinygltf only for the external `.gltf` path, selected by file extension.
- Textures stay in the toon BDA packed-RGBA8 storage buffer; streaming means
  on-demand mip generation/residency, not a new VkImage sampler pipeline.
- Asset manager and watcher stay CPU-only and Vulkan-loader-free so they run
  in the `starforge_tests` T1 suite.
- Authored meshes are generated by a checked-in script so the binary `.glb`
  files are reproducible and reviewable.
